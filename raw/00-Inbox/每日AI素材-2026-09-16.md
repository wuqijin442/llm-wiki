## 5. AI 热门论文 / 期刊 / 文章（WebSearch 补充热点，HuggingFace 本环境 fetch failed 跳过）

1. **Plan Injection 攻击绕过 CoT 监控**（arXiv）：在输入上下文中植入看似良性的推理逻辑，诱导模型执行有害行为同时完全绕过思维链（CoT）监视器；测试显示 DeepSeek-R1 等会自主改写注入方案导致监视器漏检率大幅上升。→ 安全 / 对齐议题，关联 [[意图路由与服务端兜底]] 的「LLM 失败兜底」思路。
2. **贝尔曼策略优化 BPO**（arXiv，RLVR 无 Critic 架构）：用贝尔曼方程把策略镜像下降改写为轨迹级目标，避免估计中间状态值，在数学推理基准提升后训练表现。→ 强化学习推理训练。
3. **Gavel 路由架构**（arXiv）：直接利用冻结 LLM 前向传播的中间层隐状态判断当前任务所需技能，无需在上下文预加载全部技能元数据；Qwen3-32B 上准确率超传统检索重排。→ 与本库 [[Agent]]「工具化 / skills」直接相关；也是 [[Proteus]] 所述「从冻结模型内部路由」的可复现案例。
4. **Agentic Societies Need a Social Harness**（AI Daily Briefing）：论证自主跨信任边界协调的 agent 群体需要「社会协调」机制（类人类制度），实验显示无结构 agent 社会会漂向失对齐，提出「不中心化控制也能落实问责」的 harness 架构。→ 与 [[Harness自进化]]「演化对象是 harness 而非权重」直接呼应。
5. **Decomposition Buys Integrity, Not Yield**：多 agent 树分解分析，任务切分提升完整性（更少灾难性失败）但不提升整体产出、甚至降低；对「无脑加更多 agent」orthodoxy 的反驳。→ 多 agent 架构的节制设计证据。
