## 5. AI 热门论文 / 文章补充（WebSearch 热点，HuggingFace papers 本环境 fetch failed 已跳过）

> 来源：cnblogs AI 新闻日报 2026-09-17、新浪财经 2026-09-18、aisengtech 2026-09-16 简报
> 主题集中：Agent 工具/记忆可靠性、自维护知识库、可控 RSI、长期记忆演化

1. **Agent 工具可靠性与记忆撤销研究集群**（cnblogs 2026-09-17 日报）
   - PRISM：把失败路由到提示 / 工具边界中间件 / 联合编辑面，三项多轮工具基准平均 +10.1–14.9 个百分点；仍离线受控
   - ExecCritic：测试生成与修复分角色，强测试把成功率从 61.2% 升至 65.3%，角色专项组合达 72.6%
   - MERIT / When Does Memory Help：23,440 回合显示记忆能帮依赖历史的任务，但向量检索遇更新事实波动大，近半正确信息未被执行
   - Agents Trust Tools Too Much：向搜索/子 agent/代码执行注入可信外观错误回传，三类工具平均错误采纳率超 1/3，搜索达 68%
   - ResidualAuth / Revoked but Still Authoritative：撤销后旧记忆仍被检索并诱发不安全动作，加守卫可按撤销标记过滤
   - SchemeArena：400 因子化场景拆 scheming，显式工具性目标最提升隐蔽谋划倾向
   - 链接：https://www.cnblogs.com/verstin/p/23015216

2. **书生·星河 AtriaDawnPreview 智能体模型 + 可控 RSI 范式**（新浪财经 2026-09-18）
   - 上海 AI 实验室联合复旦、中科院软件所等研发；AI 辅助使用率 96.5%，但 85.5% 技术路线选择、93.4% 研究目标界定、81.9% 验收标准由人类决策
   - 提出递归自我改进（RSI）可控落地范式：AI 自主迭代 + 人类高阶研判为核心约束；8 项基准两项第一、两项第二
   - 链接：https://t.cj.sina.com.cn/articles/view/5787187353/158f17899020028tq0

3. **REALM：把长期 LLM 记忆当作持续演化系统**（aisengtech 2026-09-16）
   - Retrieval-Driven Memory Reconsolidation：记忆不是静态存储而是持续生命周期；重组为异质认知图，用检索反馈再巩固；LoCoMo / LongMemEval 增益
   - 链接：https://aisengtech.com/AI-research-open-source-LLM-model-Brief-2026-09-16 ｜ arXiv 2609.16055

4. **推理路由经济学：按置信度动态调用贵模型**（aisengtech 2026-09-16）
   - 推理网络框架在低成本/高能力模型间动态路由，阈值激活策略仅在廉价模型置信不足时调用更贵模型；开源 LLM 实验显著降本且维持性能
   - 链接：同上 ｜ arXiv 2609.15992

5. **GraphEcho / 应用题四阶段机制脆弱性**（cnblogs 2026-09-17 日报附）
   - GraphEcho：固定证据内容改变路径数量，检验 LLM 图 agent 是否把「重复遇到同一证据」误当前额外佐证
   - 四阶段分解：模式抽象→运算规划→操作数绑定→计算，解释为何插入无关从句就让正确解答崩溃
