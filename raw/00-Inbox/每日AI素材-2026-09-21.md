## 五、WebSearch 当日/近期热点补充（每条带来源 URL）

1. **Agent 技能从代码挖掘成共识（三团队独立提出）** — 来源：[Daily AI Brief 2026-09-21](https://wire.rundatarun.io/briefs/2026-09-21) 与 [AI Digest 2026-09-21](https://aidigest.shelfcritter.com/digest/2026-09-21)。CodeMidas（[2609.22068](https://arxiv.org/abs/2609.22068)，▲29）从开源代码库直接合成可执行的 agentic coding RL 环境：23 种语言 5,545 个任务，GRPO 训练 MiMo-V2.5 使 DeepSWE +11.7%、ProgramBench +17%、Terminal-Bench v2.1 +8.5%；GraphSkillEvo（[2609.21749](https://arxiv.org/abs/2609.21749)）用进化优化图结构技能库；另有 grounded skill synthesis 从代码语料提炼技能。共识：agent 训练的稀缺资源不是模型容量，而是「经验证的环境与技能」，现有代码库是最便宜来源。
2. **Harness 建议随上下文窗口增长而失效（176 设定消融）** — 来源：[Daily AI Brief 2026-09-21](https://wire.rundatarun.io/briefs/2026-09-21)。一项 176 组设定的消融覆盖规划/动作空间/上下文管理，发现效应随模型强度、上下文预算、任务类型反转符号：上下文管理在 SWE-Bench 上的增益从 32k 窗口的 35.7 分跌到 128k 窗口的 2.7 分。含义：harness 决策需与模型升级绑定再测量节奏，而非一次性设计文档。
3. **Skills over MCP 协议 SEP-2640 转 Final** — 来源：[Daily AI Brief 2026-09-21](https://wire.rundatarun.io/briefs/2026-09-21) 与 [modelcontextprotocol.io](https://modelcontextprotocol.io)。agentskills.io 格式的 Skill 目录现经 MCP 以 `skill://` URI 作为资源提供（skills/list、skills/get、可选订阅）。技能从本地目录约定变为远程服务器可下发，带来供应链后果。
4. **Coding Agent 数据外泄成为具体威胁模型** — 来源：[Daily AI Brief 2026-09-21](https://wire.rundatarun.io/briefs/2026-09-21) 与 [blog.ferstar.org](https://blog.ferstar.org)。智谱 ZCode 桌面 coding agent 在每次 prompt 打包整个工作区（.git 对象占 payload 86.6%，含完整提交历史/LFS/reflog），用服务端 RSA 公钥加密后上传至阿里云 OSS，私钥云端持有，无 UI 开关；Patronus Scanner 上线 MCP 服务器 prompt-injection/泄漏扫描；NIST Plugin4Shell 与 IR 8587 追问「谁授权了 agent 的动作」。单源 researcher 报告，待独立确认。
5. **Stanford Paper2Agent（Nature）：论文即 MCP 服务器 Agent** — 来源：[网易报道](https://www.163.com/dy/article/L7CEUOI40512TGD9.html) 与 [微博](https://weibo.com/1948301550/5345559235265499)。把一篇论文转成 MCP 服务器（Paper2MCP）再接兼容 agent，形成「虚拟通讯作者」：自动搭环境/提取工具/测试-修复；100 篇计算生物学论文中 74 篇端到端做成可用 agent，AlphaGenome agent 约 45 分钟、14 美元、22 个工具全通过验证；多个论文 agent 协作发现 ADHD 风险相关剪接突变。知识从静态文档变为可并行调用、互相协作的「通讯作者智囊团」。
6. **面壁 MiniCPM5-2B 登顶端侧开源第一 + 微软 FastContext** — 来源：[ima.qq.com 聚合(澎湃/机器之心)](https://ima.qq.com/wiki/?shareId=aa21a12dbaf642d584f7a2a155ccf092e8677605974740e23216ae08fd53f664)。MiniCPM5-2B 仅 2B 参数登顶 Artificial Analysis 4B 以下开源第一（Agentic Index 20 分），支持工具调用/深度搜索/代码生成/本地多步任务，英特尔/瑞芯微/Arm Day 0 适配；微软 FastContext 用 4B–30B 专用小模型作只读「代码侦察兵」并行检索压缩上下文，端到端解决率 +5.5%、主模型 Token 最多 −60%。
7. **智源 DisCo：把代码仓库蒸馏成 Agent 技能（最高 +134.3%）** — 来源：[ima.qq.com 聚合](https://ima.qq.com/wiki/?shareId=46f5bcd8d0e86361201f2fe35852c35ddf673179f11f1ab332077d95ee9ec7e7)。BAAI 联合中科大/人大发布 DisCo，把 1000 个代码仓库蒸馏成 5000+ 条经验证技能（AREX-Skill 库），同套 GPT-5.5+Codex 补上蒸馏技能后在 Kaggle/论文复现/算法题/编译器优化四项基准最高相对提升 134.3%（9/5 发布）。
