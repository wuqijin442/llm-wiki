# AI应用开发

## 定义

面向企业业务系统、以调用大模型 API 为核心、偏工程化的应用层开发方向。区别于算法层（训练/微调模型）。

## 核心思想

把 LLM 接入业务：数据接向量库做 [[RAG]]、用 LangChain/自研 harness 串 [[Agent]]、FastAPI 包服务做限流缓存部署。本质是「会调 LLM 的后端服务」。

## 应用场景

- 知识库问答、智能客服、文档抽取、运维助手
- 电价政策问答、设备工单摘要、储能日志查询等垂直场景

## 落地优先级（2026 企业共识）

**RAG > Agent > 轻量微调 > 私有化部署 > 多模态**
