# iOS内部分发与App Store合规

## 分发四件套

| 事项 | 内容 |
| --- | --- |
| Unlisted 内部分发 | 不上架公开商店，通过链接/权限控制下载范围 |
| 隐私政策链接 | 审核与分发前必须可访问 |
| 加密出口（ERN） | 涉及加密通信的 App 需完成出口合规申报 |
| 崩溃符号化（dSYM） | 上传 dSYM 以便崩溃日志可读 |

## 常见拒审类别（素材归档）

- 重复内容（素材标注 ITMS-91054，对应关系待核实）
- 隐私条款类（5.1.x）
- "代码/功能/定位重复"类（4.3.a）

## 分发前核对项

- **签名一致性**：Team ID 位数、公司名与签名主体一致，打包分发前必须核对。
- **指纹规避**：第三方实现若带可识别指纹特征（多处可识别），评估自研替代以降低分发风险。

## 汇报纪律

合规/违规论断必须引用官方文档出处坐实证据；对外汇报用双版本（摘要 + 完整清单），见 [[个人AI工程方法论]]。

## 待核实

- ITMS-91054 与「重复内容」的对应关系来自素材原文，未对照 Apple 官方文档验证。
- 各拒审条款的具体审查细节素材仅给出类别，未附官方文档链接。
