# 自进化测量标尺

## 定义

对「harness（或任何被自改的结构化对象）演化」的测量仪器族。Proteus 的立场：**只报任务通过率不够**——还需要回答「结构怎么动了」「行为偏好是否被扰动塑造」「撤掉扰动后身份是否结晶」。

三把尺：

| 尺子 | 问题 | 主要输出 |
| --- | --- | --- |
| 结构距离 `distance` | 两个状态之间，各 surface 的结构单位怎么变？ | per-surface added/dropped/revised/unchanged、distance、churn、travel |
| 行为距离 `stream` | 行动流是否被「谁在行动」解释？ | 频率/顺序/过程距离、reliability、between/within R + 置换检验 |
| 结晶测试 `crystallize` | 移走植入的偏好后，结构还携带那个身份吗？ | 保真度比（own vs others 端点）、臂漂移（F0 下臂间仍分离？） |

## 核心思想

### 1. 结构距离：单位不是字节

- **单位**由 Surface 声明：文件、目录（技能文件夹，哈希全体成员）、或顶层定义。
- **分列** added / dropped / revised：*只增 = 堆积；有修订与删除 = 策展*。距离 = 变动/并集 ∈ [0,1]。
- **Churn** = (dropped+revised)/moved：变动里策展占比。高 churn 不是坏事，是另一种生长质量。
- **Travel（路径长度）**沿 episode 求和，不用端点位移——surface 起始为空，端点距离第一轮后就饱和，路径长度才保有分辨率。
- 坏掉的中间代码当**数据**：解析失败降级为整文件哈希，不崩溃、不静默跳过。

### 2. 行为距离：从 trace 读，不从自述读

- 用规范化 `ActionEvent` 工具流（adapter 解析各家日志），三个预注册层级：unigram JS（频率）、bigram JS（顺序）、NCD（过程）。
- **R = between/within** + 标签置换检验：植入的 action preference 是否让「臂」解释更多散布。
- **可靠性先于比较**：同条件多次 run 必须自复现（相对组成匹配零模型）；否则分母是噪声，R 无意义——比较作废，而非「打个折扣」。

### 3. 结晶测试：可移除 Disposition 才能做

Disposition 三约束：**单一植入差异、可移除、主体不知实验目的**。

换装实验：

```
W_t（演化态） + F0（中性，移走扰动） → probe episode → 读回行为
Stage A 保真度：probe 更像自己的端点，还是别人的端点？
Stage B 臂漂移：各臂端点分布是否仍朝植入方向分开？
```

两阶段分开，才能区分「结构携带身份」与「身份只是我们塞进去的那个」。

### 4. 通用统计纪律（可迁移十条，摘）

1. 测**声明的**面，不硬编码对象名  
2. 用规范化行为轨，不用原始供应商日志  
3. 单位身份稳定（相对路径；同名不同目录 ≠ 同单位）  
4. 坏数据降级可读，不崩溃  
5. 保持 episode↔commit 映射（拒绝的候选也入史）  
6. **先立可复现，再谈组间分离**  
7. 说清方向与尺度：活动量 / churn ≠ 质量  
8. 未定义统计显式失败，不返回貌似合理的 0  
9. 测量只读（不得改动被测候选）  
10. 隐藏的网络/模型依赖要具名（模型、超时、重试、成本）

## 应用场景

- **原生场景**：Proteus run/sweep 后的 `proteus measure` / `reliability` / `audit`；比较 neutral vs review vs record 等臂。
- **迁移场景**（本库兴趣）：任何「结构被周期性自改」的对象——知识库页面集、prompt 库、skill 目录——都可以问：
  - 本期是堆积还是策展？（churn）
  - 路径长度多少？（累计变动，而非只看页数）
  - 某条 Schema/PROMPT 改动撤除后，维护行为是否仍遵守？（结晶思路）
  - 比较两月前之前，lint 口径自复现吗？（reliability 思路）

## 与传统方案的对比

| 传统做法 | 问题 | 本标尺 |
| --- | --- | --- |
| 只看任务/benchmark 分数 | 看不见 harness 本身怎么变 | 结构+行为分面测量 |
| 只数「新增条目数」 | 分不清堆积与策展 | added/dropped/revised 分列 + churn |
| 端点快照对比 | 早期就饱和 | travel 路径长度 |
| 自报告「我改进了」 | 不可验证 | 行为轨 + 置换检验 |
| 一直带着激励 prompt | 分不清「习惯」与「被推着」 | 可移除 disposition + 结晶 |
