# Dify

## 概述

langgenius/dify：构建 Agentic workflows 与 RAG 管道的一站式协作平台。支持多种 AI 模型与工具，可部署于云、VPC 或自托管。

## 背景

GitHub 上的 AI 应用低代码开发平台，长期位于 AI/Vibe-coding 生态热门（⭐152.1k）。

- **Agentic workflow** 可视化编排
- **RAG 管道** 构建
- 多模型、多工具支持，低代码/无代码
- 云 / VPC / 自托管部署
