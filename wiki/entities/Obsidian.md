# Obsidian

## 概述

基于本地 markdown 文件的知识管理工具。所有数据是本地 `.md` 文件，无云端锁定，可用 Git 管理版本。

## 背景

笔记领域中主打"纯本地 + 可定制"的 Markdown 生态工具，因其双向链接与插件体系成为 PKM（个人知识管理）主流选择之一。

## 关键特性

- **纯本地存储**：所有数据为本地 `.md` 文件，随时可用 Git 管理版本
- **双向链接**：原生支持 `[[双链]]` 语法
- **图谱视图**：可视化展示页面关联，一眼看清知识结构
- **插件生态**：Dataview、Web Clipper 等插件扩展能力强

## 使用方式

- 下载自 obsidian.md，支持 macOS / Windows / Linux / 移动端
- 创建 vault（普通文件夹，无私有格式）
- 通过设置配置附件路径、每日笔记、模板
- 可搭配社区插件（Dataview / Web Clipper / Excalidraw / Marp）

## 优缺点

### 优点
纯本地、双链、图谱、插件丰富、免费

### 缺点
多端同步需靠 Git / iCloud / Syncthing / Obsidian Sync 等外部方案
