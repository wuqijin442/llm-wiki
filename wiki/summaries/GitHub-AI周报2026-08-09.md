# GitHub AI周报2026-08-09摘要

> 来源素材：[[raw/10-Work/GitHub-AI周报-2026-08-09]]（来自 `AI_Project_Weekly/Obsidian_Vault/Weekly`）

## 核心要点

1. **「技能层」拿走一半增量**：reverse-skill / TencentDB-Agent-Memory / book-to-skill / google/skills 合计 🔺22,895，占 Top 10 总增 50.2%。
2. **周冠军 reverse-skill**：首个以垂直专业领域登顶（逆向/渗透/安全技能路由包），⭐22.0k，总分叉出「领域 know-how」护城河。
3. **本地推理双雄**：airllm（分层推理，Kimi K3 跑进 4GB）与 ds4/DwarfStar（窄而深原生引擎，8×L40S 120 t/s）从两端夹击同一前提。
4. **编码 Agent 本体降温**：Agent 工具链 Top 10 从 6 席降至 2 席，注意力转向「给 Agent 装什么」。
5. **两个存量大盘异动**：AI-For-Beginners（五年前教程单周+7.5k）、ComfyUI 均判定为频道流量而非赛道信号，标注待复核。

## 详细摘要

### Top 10 概览
reverse-skill(🔺9,635/PowerShell)、TencentDB-Agent-Memory(🔺8,046/TS)、AI-For-Beginners(🔺7,469)、airllm(🔺5,711)、Reasonix(🔺4,704/Go)、book-to-skill(🔺4,071)、openwork(🔺1,834)、ComfyUI(🔺1,778)、ds4(🔺1,254/C)、google/skills(🔺1,143)。合计 🔺45,645。

### 关键趋势
- **技能供给四种商业位置**：垂直手艺（reverse-skill）/ 自家独家知识（google/skills）/ 造技能的机床（book-to-skill）/ 可治理团队资产（TencentDB）。
- **注意边界**：reverse-skill 的 `RULES` 层在 ACT 前设 scope gate，授权先确认再执行——安全技能包的合规底线。
- **DS4 与 DGX Spark 相关**：CUDA 后端点名支持 DGX Spark，Metric (96GB+ Mac) / ROCm。
