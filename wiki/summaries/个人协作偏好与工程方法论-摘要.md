# 个人协作偏好与工程方法论 - 摘要

本次 ingest 从本机 WorkerBuddy / Trae 记忆（已脱敏）提炼，沉淀个人长期可复用的**协作纪律**与**工程方法论**。

## 沟通
- 中文；偏好结论先行、表格对比、编号问题汇总、根因分析。
- 对无验证结论会要求截图 / refs / git diffs 交叉比对；AI 先看图再分析。
- 单字指令驱动（改/排/删掉）；确认环节简短指令式按编号推进。

## 工作纪律（AI 侧）
- 只改前端不碰后端；未经批准不自动构建 / 提交；最小 diff。
- 零 `??` / `?.` 新语法、零硬编码英文文案；给路径先校验再执行。
- 用户改 UI 决策 AI 跟随 revert；改错恢复原代码重做；倾向彻底删除留备份须确认。

## 核心方法
- 精度类 Bug：截图 + diff + 场景模拟三重验证，四列表格呈现（根因/变更/场景模拟/验证）。
- 证据优先：用实测（抓包/计数器/git diff）反驳后端冲突结论。
- 跨平台问题（Android/Windows）一并覆盖。
- 会话级记忆：日期 md / 项目 MEMORY.md / work-log，跨 session 跟进。
