# 每日 AI 素材（2026-09-19 晚间）摘要

> 本批为同日第二次采集。GitHub Trending / Gitee LLM / arXiv cs.AI 与早间同口径（数值为当日累计）；**本轮主要新增信号来自 WebSearch 当日热点**（harness 成本实证、边缘自动化模型、多模态推理优化、AI 治理合规）。CSDN 热榜接口再次仅返回作者+浏览量，降级处理。

## 信号一：Harness 成本/价值成为独立研究主题

延续早间「harness 组件级科学化」脉络，本轮出现可被引用的实证：
- **HarnessTax（UC Berkeley + Arena，09-16）**：同一模型在 Claude Code / Codex CLI / Pi 三套 harness 上跑 SWE-bench Lite + Terminal-Bench 2.0，**任务成功率几乎不变、成本差最高 5x**；机制是 harness 每请求输入 token 量（Claude Code ~27k / Codex ~15k / Pi ~2.6k）。结论：边际藏在工具层而非模型层，「harness tax」值得单独度量。
- **arXiv 2609.20474《How Do Agent Harnesses Create Value?》**：从规划信息（planning information）与释放控制（release control）角度量化 stateful LLM agent 的价值来源。
- **arXiv 2609.20804《An Empirical Study of Harness Design for Coding Agents》**：对脚手架（规划能力 / 动作空间 / 上下文管理）做系统性消融。
- **arXiv 2609.20519《SoL-Pi》**：递归自扩展 auto-research loops，提升 agent harness 效率。

> 与 [[Harness自进化]] 的「演化对象=harness」主张形成第四次外部印证；与 [[自进化测量标尺]]「先测 harness 再谈模型」纪律同构。

## 信号三：微型 / 边缘端自动化基础模型

- **cactus-compute/needle**（GitHub 今日 +207）：2-bit、8–29MB 的自动化基础模型，跑在手机/穿戴/智能家居/机器人/车载 MCU 上，做工具调用、结构化抽取、嵌入。
- **Cactus Needle 3**（AGI HUNT）：2-bit、25M–121M 参数、8–29MB 二进制；Raspberry Pi 5 上宣称 4k tok/s decode；单 checkpoint 含 2–20 个独立可部署子网络（自动化专用，无 chat）。
- **AutoArk Edge0**（AGI HUNT）：35B 模型专家权重落 SSD、按需流式加载，24GB M4 Pro 上 3GB 活跃内存达 20.4 tok/s（标准法 3.9 tok/s / 18GB），Apache 2.0。

> 边缘推理从「断网能聊」走向「本地干大活」，与 [[本地优先AI创作]]「硬件预算内调度」同源但场景不同（消费级 MCU vs 创作工作站）。

## 信号四：多模态 / 视频推理优化

- **vLLM + 英伟达 PyNvVideoCodec 硬件视频解码**：多卡视频描述任务 CPU 解码过载瓶颈突破，VLM 直接调用专用硬件预处理帧。
- **Kijai MiniMax-H3 VAE 更新**：RTX 3060 12GB + 16GB RAM 从 0.8MP@10s 提升至 1MP×10s / 0.7MP×15s，无质量下降。
- **LingBot-World 2.0 1.3B**：单 RTX 5090 上 6→16 FPS（降精度 + SageAttention + 自定义 kernel）。

> 视频/多模态吞吐优化与 [[本地优先AI创作]] 的视频生成管线硬件约束相关，但本库无专门页，留待相关素材累积后再建概念页。

## 信号五：AI 治理 / 合规升温

- **加州 AI kill switch 行政令**：Newsom 指示研究前沿 AI 公司强制「kill switch」+ 独立验证/审计标准，两月内出建议。
