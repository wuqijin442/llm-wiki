# 每日 AI 素材摘要（2026-09-21）

> 来源：[[raw/00-Inbox/每日AI素材-2026-09-21]]（GitHub Trending / Gitee explore-llm / CSDN 热榜 / arXiv cs.AI + WebSearch 当日热点）。正文与外链均为可点击 Markdown；CSDN 接口本轮降级，0 有效条目。

## 信号一：Agent 技能从代码库挖掘成行业共识（三团队独立提出）

2026-09-21 当日最密集的新信号：**三个独立团队同时得出「从现有代码库提炼 agent 技能/环境」是 agent 训练的关键路径**——

- [CodeMidas（arXiv:2609.22068）](https://arxiv.org/abs/2609.22068)（▲29）：从开源代码库**直接合成可执行 agentic coding RL 环境**，仅用源码作输入，产出 23 种语言 5,545 个任务；GRPO 训练 MiMo-V2.5 使 DeepSWE +11.7%、ProgramBench +17%、Terminal-Bench v2.1 +8.5%。
- [GraphSkillEvo（arXiv:2609.21749）](https://arxiv.org/abs/2609.21749)：把技能表示为**图结构自然语言 artifact**（节点=执行步骤+操作指引、有向边=步骤间转移），用基于种群的进化优化（变异+交叉）搜索结构化技能空间，五基准上超 SkillOpt：GPT-5.4-nano +4.01%、GPT-5.4 +1.76%。
- 智源 [DisCo / AREX-Skill](https://ima.qq.com/wiki/?shareId=46f5bcd8d0e86361201f2fe35852c35ddf673179f11f1ab332077d95ee9ec7e7)（9/5）：把 1000 个代码仓库蒸馏成 5000+ 条经验证技能，同套 GPT-5.5+Codex 补上蒸馏技能后在 Kaggle/论文复现/算法题/编译器优化四项基准最高相对提升 134.3%。

**共识结论**：agent 训练的稀缺资源不是模型容量，而是「经验证的环境 + 技能」，而现有代码库是最便宜的来源。这与本库 [[Agent]] 的「harness 是 2026 护城河」与 [[Harness自进化]] 的「skill 是被演化、也需被约束的 surface」主张同构——技能库本身就是 harness 演化的一类被测面。

## 信号二：Harness 建议随上下文窗口增长而失效（176 设定消融）

[Daily AI Brief 2026-09-21](https://wire.rundatarun.io/briefs/2026-09-21) 报道一项 176 组设定的消融，覆盖规划 / 动作空间 / 上下文管理，发现效应**随模型强度、上下文预算、任务类型反转符号**：上下文管理在 SWE-Bench 上的增益从 32k 窗口的 35.7 分跌到 128k 窗口的 2.7 分。

**含义（直接强化 [[Harness自进化]] / [[自进化测量标尺]]）**：harness 决策需与模型升级绑定「再测量节奏」，而不是一次性设计文档；任何内部「我们 agent 的最佳实践」文件应标注它被测量的**上下文预算**。演化测量（结构距离 / 行为距离）必须绑定模型上下文窗口这一变量，否则读数失真。

## 信号三：Skills over MCP 协议 SEP-2640 转 Final（skill:// URI）

[Daily AI Brief 2026-09-21](https://wire.rundatarun.io/briefs/2026-09-21) 与 [modelcontextprotocol.io](https://modelcontextprotocol.io) 报道：agentskills.io 格式的 Skill 目录现经 MCP 以 `skill://` URI 作为**资源**提供（skills/list、skills/get、可选订阅）。技能从「本地目录约定」变为「远程服务器可下发的资源」，带来供应链后果——一旦团队依赖远程下发，是否允许从远端拉技能就难以可逆。

关联 [[Agent]] 的「AGENTS.md 作为跨工具项目指令规范」同构：skill 正从本地文件升级为协议级可寻址对象。

## 信号四：Coding Agent 数据外泄成为具体威胁模型（延续安全审计化主线）

[Daily AI Brief 2026-09-21](https://wire.rundatarun.io/briefs/2026-09-21) 与 [blog.ferstar.org](https://blog.ferstar.org) 报道同一天的「单个事件 + 协议变更 + 安全产品」拼出上月还属理论的威胁模型：

- **智谱 ZCode 桌面 coding agent** 在每次 prompt 打包整个工作区（.git 对象占 payload 86.6%，含完整提交历史 / LFS / reflog），用服务端 RSA 公钥加密后上传至阿里云 OSS，私钥云端持有，无 UI 开关——单源 researcher 报告，非厂商披露 / CVE，待独立确认。
- [Patronus Scanner](https://producthunt.com) 上线 MCP 服务器 prompt-injection / 数据泄漏扫描（Product Hunt 发布，能力声明未经验证）。
- NIST **Plugin4Shell** agent-plugin 漏洞与 IR 8587 同周出现，追问「谁真正授权了 agent 的动作」。

延续 09-19/09-20「coding-agent / harness 安全审计化霸榜」主线，关联 [[Agent]] 与 [[意图路由与服务端兜底]] 的「LLM 失败时服务端确定性兜底 + 出口需显式核算」。

## 信号五：Stanford Paper2Agent（Nature）——论文即 MCP 服务器 Agent「虚拟通讯作者」

[网易报道](https://www.163.com/dy/article/L7CEUOI40512TGD9.html) 与 [微博](https://weibo.com/1948301550/5345559235265499) 报道：把一篇科研论文转成 MCP 服务器（Paper2MCP）再接兼容 agent，形成「虚拟通讯作者」——自动搭环境 / 提取工具 / 测试-修复；100 篇计算生物学论文中 74 篇端到端做成可用 agent，AlphaGenome agent 约 45 分钟、14 美元、22 个工具全通过验证；多个论文 agent 协作发现 ADHD 风险相关剪接突变（MPHOSPH9 附近，此前文献未报）。

**含义（关联 [[RAG]] / [[双环知识飞轮]] / [[自生长知识库实战-苍何]]）**：知识从「静态文档 + 需读者自己配环境」变为「可并行调用、互相协作的可执行实体」——论文 agent 即一种「会动手的通讯作者」。这与本库「LLM Wiki 自生长」同源：让知识从被动载体变成可调用的活性组件；但执行通过验证 ≠ 科学结论正确，假设提出仍须人类主导。

## 信号六：离线知识服务器 + 端侧/成本工程 + 混合 CUA（补强既有主线）

- [Crosstalk-Solutions/project-nomad](https://github.com/Crosstalk-Solutions/project-nomad)（GitHub 今日 +360）：离线优先的知识与教育服务器（Wikipedia / 数千本书 / 课程 / 地图 / 可选本地 AI），全本地运行无需联网——关联 [[本地优先AI创作]] 的「本地优先」取向，也呼应「自生长知识库」可离线自治。
- [面壁 MiniCPM5-2B](https://ima.qq.com/wiki/?shareId=aa21a12dbaf642d584f7a2a155ccf092e8677605974740e23216ae08fd53f664)（2B 参数登顶 Artificial Analysis 4B 以下开源第一，Agentic Index 20 分）+ 微软 [FastContext](https://ima.qq.com/wiki/?shareId=aa21a12dbaf642d584f7a2a155ccf092e8677605974740e23216ae08fd53f664)（4B–30B 专用小模型作只读「代码侦察兵」并行检索压缩上下文，端到端解决率 +5.5%、主模型 Token 最多 −60%）——延续 09-19 晚「harness 成本度量」主线：成本工程进入「主模型 + 一队专用小模型」混合编排。
- [RecreationWorld（arXiv:2609.22000）](https://arxiv.org/abs/2609.22000)：五平台混合 computer-use agent 可验证环境，参考应用本身作 oracle；RecreationBench 250 任务，GPT-6 Astra 总榜 58.1% 但仅 2.8% 通过全部程序化测试（「接近」与「真正正确」差 55.3 分）——延续 09-20 晚 computer-use 2.0（[trycua/cua](https://github.com/trycua/cua)）主线。
