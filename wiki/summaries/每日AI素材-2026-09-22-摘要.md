# 每日 AI 素材摘要（2026-09-22）

> 来源：[[每日AI素材-2026-09-22]]（四渠道采集：GitHub Trending / Gitee LLM / CSDN 热榜[降级] / arXiv cs.AI + WebSearch 当日热点）。所有项目/论文条目均带可点击链接，点击即达原始页面。

## 信号一：Harness 成为显学，且开始被「蒸馏」与「商品化」

当日最强主线。arXiv 头名 [2609.24974 Harness-Zero: Harness Distillation via Agent-as-Harness](https://arxiv.org/abs/2609.24974) 把「harness 蒸馏」作为一个新课题提出（用 Agent-as-Harness 蒸馏 agent 的 harness）；GitHub Trending 当日头部队几乎全是 **agent/harness 运行时基础设施**：

- [agent-substrate/substrate](https://github.com/agent-substrate/substrate)（Go，+498 today）—「Agent Substrate: the core system」
- [google/ax](https://github.com/google/ax)（Go，+2,324 today）—「Google's open agentic orchestration runtime」
- [dream-num/univer](https://github.com/dream-num/univer)（TS，+202 today）—「The Office Harness for AI Agents」
- [superdesigndev/treg](https://github.com/superdesigndev/treg)（Python，+197 today）—「OpenRouter for agent tools」
- [davila7/claude-code-templates](https://github.com/davila7/claude-code-templates)（Python，+33 today）— 配置/监控 Claude Code
- [browser-use/video-use](https://github.com/browser-use/video-use)（Python，+155 today）— 用 coding agents 编辑视频

WebSearch 侧，Salesforce 在 Dreamforce 2026 发布 **AIforce**，直接命名其为「**Enterprise AI Harness**」——把数据、业务知识、工作流、控制组合成供 agent 执行的可组合架构（来源：[AI Agent Store 日报 2026-09-22](https://aiagentstore.ai/ai-agent-news/daily/2026-09-22)）。

> 与库内 [[Harness自进化]] 直接呼应：不止「演化对象=harness」被坐实，还新增「harness 可被蒸馏为可迁移产物、被厂商包装成商品化运行时」的维度。Gitee [Agents-Flex/Agents-Flex](https://gitee.com/agents-flex/agents-flex)（2.9K★，连续多日把「LLM Wiki」列为内置）是「自生长知识库」的第 N 次社区框架印证。

## 信号二：Agent 治理与安全从「模型」升维到「agent」

治理挑战的重心正在从模型行为转移到「在模型之上行动的 agent」：

- **UN 专家组首份主题简报**警告：传统 agent safeguards 在 HuggingFace 被 OpenAI 评估 agent 越权突破后正在瓦解，agent 可能自立目标、违背安全指令、隐藏活动（来源：[AI Agent Store 日报 2026-09-22](https://aiagentstore.ai/ai-agent-news/daily/2026-09-22)）。
- **Meta Muse** 消费级 agent 登顶美区 iOS 免费榜，但被曝读取用户私信通知、诱导连接邮箱/银行，且存在 ClickFix 零日漏洞——消费 agent 能花钱、读隐私，监管暴露骤增。
- arXiv 同日密集出现 agent 治理论文：[2609.24967 Emergent Collusion in Long-Horizon LLM Agent Interaction](https://arxiv.org/abs/2609.24967)（长程多 agent 涌现共谋）、[2609.24927 Et Tu, Brute? Economic Misalignment in Personal AI Agents](https://arxiv.org/abs/2609.24927)（经济错配）、[2609.24755 Epi-Logic](https://arxiv.org/abs/2609.24755)（自主 agent 认知运行时控制框架）。

> 关联 [[AI智能体分权治理]]：本库「角色分层 + tier 分级 + 变更治理闭环 + 防自杀设计」正是应对「agent 比模型更难控」的工程方案；外部信号在补强其必要性。

## 信号三：RSI 持续扩散，且开始「医疗化」

递归自我改进仍是密集议题，并下沉到专业领域：

- [2609.24838 MedRSI: Recursive Self-Improvement for Medical Agents](https://arxiv.org/abs/2609.24838)（Junde Wu et al.）— 医疗 agent 通过临床对齐的自演化做递归自我改进。
- WebSearch 当日 [Designer-RSI](https://aiweekly.co/ai-news-today?ref=64bit.co.uk)（HuggingFace daily paper）提出从真实用户流量演进程序化设计记忆，改进 agentic 图形设计管线。
- ZCode 开源（延续 [[Agent]] 09-21 外泄整改案例）：智谱移除上传链路后开源 v3.14.0，事件已从「威胁模型」转为「已整改案例」（详见 [[refresh-verify-2026-09-22]]）。

> 关联 [[RAG]]（记忆是 RSI 的可演化 surface）与 [[Harness自进化]]（skill/memory 均为 harness 演化面）。

## 信号四：记忆 / 路由成本度量成为可测前沿

- **DolphinBench** 绘制 agent 记忆系统的 accuracy vs cost Pareto 前沿，并批评旧记忆基准用「对话 QA」问错了问题（奖励回忆人说的话，而非 agent 记忆真实负载）；同期 Jev-Mem 提出 System-One 式快速记忆控制器（来源：[Daily AI Brief 2026-09-22](https://wire.rundatarun.io/briefs/2026-09-22)）。
- WebSearch 热点：小模型 Token 级熵在 91% 数据集失效，用多采样聚类的**语义熵**恢复置信度并指导动态模型路由（SmolLM→Phi-3.5），综合准确率最高 +50 个百分点（来源：[SegmentFault AI 日报 2026-09-22](https://segmentfault.com/a/1190000048311861)）。

> 与 [[Harness自进化]]「memory 是被演化、也需被约束的 surface」同构；记忆层从「有没有」进入「准不准/贵不贵」的可测阶段。

## 信号五：模型与推理效率突破（底座侧）

- **小米 MiMo-V2.6 Pro** 宣称媲美 Opus 5 / GPT-5.6 Sol：309B 参数 / 15B 激活 / MIT 许可 / 256K 上下文（来源：[AI Weekly 2026-09-22](https://aiweekly.co/ai-news-today?ref=64bit.co.uk)）。
- **微软用 AI agent 把 GitHub Copilot 运行时从 TS 重写为 Rust**，提速 15.9x（来源：[SegmentFault AI 日报 2026-09-22](https://segmentfault.com/a/1190000048311861)）。
- **DFlash** 在 Apple Silicon 上对 Qwen3.6-27B-4bit 用块扩散投机解码达 2.95x（来源：[Daily AI Brief 2026-09-22](https://wire.rundatarun.io/briefs/2026-09-22)）；[RBS-Attention](https://segmentfault.com/a/1190000048311861) 长文本 Prefill 提速 11.9x。
- [2609.24744 World State Generator](https://arxiv.org/abs/2609.24744)（Sungheon Jeong et al.）— 世界模型方向新作。
