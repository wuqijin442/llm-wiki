# 📊 知识库仪表盘

> 本页使用 Dataview 插件动态查询 wiki 页面。安装 Dataview 后会自动渲染。
> 安装方式：Obsidian 设置 → 社区插件 → 搜索 `Dataview` → 安装并启用。

## 最近更新的页面

```dataview
TABLE description, updated
FROM "wiki"
SORT updated DESC
LIMIT 10
```

## 概念页（按分类）

```dataview
LIST description
FROM "wiki/concepts"
```

## 实体页（工具/框架）

```dataview
LIST description
FROM "wiki/entities"
```

## AI 相关页面

```dataview
LIST description
FROM "wiki"
WHERE contains(tags, "AI")
```

## 待补充 Empty

```dataview
TABLE description
FROM "wiki"
WHERE !description OR description = ""
```
