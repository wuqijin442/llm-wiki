# 📊 知识库仪表盘

> 本页使用 Dataview 插件动态查询 wiki 页面。安装 Dataview 后会自动渲染。
> 安装方式：Obsidian 设置 → 社区插件 → 搜索 `Dataview` → 安装并启用。

## 导航

- [[index]] — 全局索引（LLM 的检索入口）
- [[growth]] — 🌱 生长看板（未消化素材 / 孤岛 / 缺字段 / 过时）
- [[lifecycle]] — 🔄 生命周期台账（成熟度与复核节奏）

---

## 最近更新的页面

```dataview
TABLE description, updated
FROM "wiki"
WHERE contains(file.folder, "wiki/") AND !contains(file.folder, "logs")
SORT updated DESC
LIMIT 10
```

## 概念页（按分类）

```dataview
LIST description
FROM "wiki/concepts"
```

## 实体页（工具/框架）

```dataview
LIST description
FROM "wiki/entities"
```

## AI 相关页面

```dataview
LIST description
FROM "wiki"
WHERE contains(file.folder, "wiki/") AND !contains(file.folder, "logs") AND contains(tags, "AI")
```

## 待补充 Empty

```dataview
TABLE category AS 分类, updated AS 更新
FROM "wiki"
WHERE contains(file.folder, "wiki/") AND !contains(file.folder, "logs") AND (!description OR description = "")
```

## 状态分布

```dataview
TABLE length(rows) AS 页数
FROM "wiki"
WHERE contains(file.folder, "wiki/") AND !contains(file.folder, "logs")
GROUP BY status
SORT length(rows) DESC
```
